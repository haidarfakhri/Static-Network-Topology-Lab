# Static Routing Topology Analysis

## Overview
This project compares two static network topologies: Direct Interconnection vs. Intermediate Router Segmentation.

## Files Included
- `Network_Analysis_Report.md`: Detailed technical analysis.
- `Static Routing (2 & 3 Routers).pkt`: Cisco Packet Tracer configuration file.
- `Topology A.png`: Visual Representation of the 1st Network Topology (2 Routers).
- `Topology B.png`: Visual Representation of the 2nd Network Topology (3 Routers).
  
## Prerequisites
- Cisco Packet Tracer Version 9.0.1.0858
